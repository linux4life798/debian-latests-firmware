# Debian Latest Firmware

A no-frills linux-firmware Debian mono package, which installs the latest tagged
firmware from the upstream [linux-firmware repo](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git).
This is useful if you are having issues running Debian on new hardware, that
may have firmware fixes released frequently.

**Checkout this repo's
[releases page](https://github.com/linux4life798/debian-latest-firmware/releases)
for the latest pre-built Debian package binaries.**

---

This repo tracks the official upstream linux-firmware with minimal changes to
support building a Debian binary release package.
